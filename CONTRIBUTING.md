# Contributing

The numbered notebooks in the repository root are the source of truth. Each
notebook starts with `#| default_exp <module>`; mark code to publish with
`#| export` (or `#| exporti` for internal code). `optimisations/*.py` and
`optimisations/_modidx.py` are generated by nbdev. Edit the notebook, not the
generated Python file. `index.ipynb` generates the README.

Use Python 3.10 or newer:

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install -e '.[dev]'
nbdev-install-hooks
nbdev-export
python -m unittest discover -s tests
nbdev-test
```

To regenerate the README and documentation, install
[Quarto](https://quarto.org/docs/get-started/) and run `make docs`. The current
site is generated into `_docs/`; `docs/` contains a historical Jekyll snapshot,
not the current documentation. In CI, the exported Python modules and README
must match their notebook sources.

MP4 rendering requires an `ffmpeg` executable. Prefer `output='js'` for
portable examples and tests. Long-running animation examples use
`#| eval: false` so they remain available interactively without making every
documentation build render a video.
